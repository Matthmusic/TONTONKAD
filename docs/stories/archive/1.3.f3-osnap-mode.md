# Story 1.3 : Mode OSNAP F3 — accroche géométrique sur fourreaux

## Status

Ready for Review

---

## Story

**As a** électricien ou bureau d'études utilisant TontonKAD,
**I want** pouvoir activer une accroche magnétique aux points géométriques des fourreaux existants en appuyant sur F3,
**so that** je puisse aligner précisément un fourreau sur le centre ou le bord d'un autre fourreau, comme en mode OSNAP dans AutoCAD.

---

## Acceptance Criteria

1. La touche `F3` (sans modificateur) bascule le mode OSNAP ON/OFF globalement.
2. Un bouton dans la toolbar permet également de toggler le mode OSNAP.
3. En mode OSNAP ON, pendant un drag de fourreau, le curseur s'accroche magnétiquement aux points suivants des fourreaux existants (excluant l'objet dragué) :
   - **Centre** du fourreau (x, y)
   - **Quadrant Nord** (x, y - r)
   - **Quadrant Sud** (x, y + r)
   - **Quadrant Est** (x + r, y)
   - **Quadrant Ouest** (x - r, y)
4. L'accroche se déclenche si le curseur est dans un rayon de `OSNAP_RADIUS = 20px` (coordonnées canvas) du point candidat.
5. Quand un point OSNAP est actif, `snapPreviewPoint` est mis à jour avec `{ x, y, timestamp, osnapType: 'center'|'quadrant' }`.
6. `drawSnapPreview()` utilise `snapPreviewPoint.osnapType` pour adapter le visuel :
   - `'center'` → cercle doré pulsant (couleur `rgba(255, 200, 0, ...)`)
   - `'quadrant'` → losange doré pulsant (même couleur, forme différente)
7. L'OSNAP a la **priorité la plus haute** : OSNAP > snap-grille > position libre.
8. En mode OSNAP ON, le `snapPreviewPoint` existant (grille) est remplacé par le point OSNAP si un candidat est trouvé dans le rayon.
9. Un indicateur visuel dans la toolbar : bouton avec classe `btn-active` quand OSNAP ON.
10. Le mode OSNAP est **compatible** avec ORTHO (F8) — les deux peuvent être actifs simultanément. L'accroche OSNAP est calculée en premier, puis la contrainte ORTHO est appliquée si besoin.
11. En mode OSNAP OFF, le comportement est identique à l'état actuel (aucune régression).
12. L'OSNAP ne s'applique qu'aux fourreaux en drag — pas aux câbles (trop petits, trop nombreux).

### Fonction `snapToObjects()` — implémentation de référence

```javascript
function snapToObjects(x, y, ignoreId) {
  let best = null;
  let bestDist = OSNAP_RADIUS;

  for (const f of fourreaux) {
    if (f.id === ignoreId) continue;
    const r = f.od * MM_TO_PX / 2;

    const candidates = [
      { x: f.x,     y: f.y,     osnapType: 'center'   },
      { x: f.x,     y: f.y - r, osnapType: 'quadrant' }, // Nord
      { x: f.x,     y: f.y + r, osnapType: 'quadrant' }, // Sud
      { x: f.x + r, y: f.y,     osnapType: 'quadrant' }, // Est
      { x: f.x - r, y: f.y,     osnapType: 'quadrant' }, // Ouest
    ];

    for (const pt of candidates) {
      const d = Math.hypot(x - pt.x, y - pt.y);
      if (d < bestDist) {
        bestDist = d;
        best = { x: pt.x, y: pt.y, osnapType: pt.osnapType };
      }
    }
  }
  return best; // null si aucun point dans le rayon
}
```

### Intégration dans `onMove()` — ordre de priorité

```javascript
// Dans onMove(), bloc fourreau, AVANT targetPos :

let osnapPoint = null;
if (osnapEnabled) osnapPoint = snapToObjects(p.x, p.y, f.id);

if (osnapPoint) {
  // OSNAP prioritaire : skip snap-grille et ORTHO
  targetPos = osnapPoint;
  snapPreviewPoint = { x: osnapPoint.x, y: osnapPoint.y, timestamp: Date.now(), osnapType: osnapPoint.osnapType };
} else {
  // Comportement normal : snap-grille puis ORTHO
  let targetPos = (gridEnabled && snapToGrid) ? snapPointToGrid(p.x, p.y) : p;
  if (orthoEnabled && dragStartPos) { /* ... contrainte ORTHO existante ... */ }
}
```

**Note** : quand OSNAP accroche, ne pas appliquer ORTHO par-dessus (l'accroche est intentionnelle et précise). Si l'utilisateur veut ORTHO + OSNAP, l'OSNAP se déclenche seulement si le point candidat est dans le rayon — sinon ORTHO prend le relais.

### Adaptation `drawSnapPreview()` — visuel OSNAP

```javascript
// Dans drawSnapPreview(), après la récupération du theme :
const isOsnap = snapPreviewPoint.osnapType === 'center' || snapPreviewPoint.osnapType === 'quadrant';
const baseColor = isOsnap ? '255, 200, 0' : (theme === 'dark' ? '255, 145, 77' : '255, 120, 50');

// Pour osnapType === 'quadrant' : remplacer le cercle de contour par un losange
if (snapPreviewPoint.osnapType === 'quadrant') {
  const s = haloRadius * 0.6; // taille du losange
  ctx.beginPath();
  ctx.moveTo(snapPreviewPoint.x, snapPreviewPoint.y - s); // haut
  ctx.lineTo(snapPreviewPoint.x + s, snapPreviewPoint.y); // droite
  ctx.lineTo(snapPreviewPoint.x, snapPreviewPoint.y + s); // bas
  ctx.lineTo(snapPreviewPoint.x - s, snapPreviewPoint.y); // gauche
  ctx.closePath();
  ctx.stroke();
} else {
  // cercle existant (centre ou snap-grille)
  ctx.arc(snapPreviewPoint.x, snapPreviewPoint.y, haloRadius, 0, Math.PI * 2);
  ctx.stroke();
}
```

### Coordonnées : canvas pixels vs mm

- `f.x`, `f.y` dans `fourreaux[]` sont en **coordonnées canvas pixels**
- `f.od` est en **mm** → convertir avec `MM_TO_PX` : `r = f.od * MM_TO_PX / 2`
- `OSNAP_RADIUS = 20` est en **pixels canvas** — pas besoin de conversion
- `p = canvasCoords(ev)` retourne des coordonnées canvas pixels — cohérent

### Compatibilité ORTHO + OSNAP (AC: 10)

Quand les deux sont actifs :
- Si OSNAP trouve un point → utiliser ce point directement (ne pas appliquer ORTHO par-dessus)
- Si OSNAP ne trouve rien → appliquer ORTHO normalement

Cela garantit qu'une accroche précise sur un quadrant ou centre ne soit pas déformée par la contrainte ORTHO.
