# Story 3.4 : Hub inventaire — sélecteur quantité + modes A/B/C

## Status

Ready for Review

---

## Story

**As a** utilisateur de TontonKAD,
**I want** un inventaire de fourreaux avec contrôles de quantité [−][+], un compteur [placés/total], et 3 modes de placement déclenchés contextuellement,
**so that** je puisse définir mon besoin en fourreaux avant de placer, et basculer naturellement entre placement instinctif (A), automatique (B) et guidé (C) sans choisir explicitement de mode.

---

## Acceptance Criteria

1. Le sélecteur de fourreau dans la toolbar inclut un champ quantité `[−] N [+]` et un bouton `[+ Ajouter à l'inventaire]`.
2. Cliquer `[+ Ajouter]` avec un type + quantité N ajoute ou met à jour l'entrée dans la liste inventaire avec compteur `[0/N placés]`.
3. L'inventaire affiche chaque type de fourreau avec : nom, contrôles `[−][+]` pour ajuster la quantité totale, barre de progression ou compteur `[X placés / N total]`.
4. **Mode A** (ADN actuel conservé) : sélectionner un type dans la toolbar + clic direct canvas → placement immédiat avec gravité. Ce fourreau est automatiquement ajouté/incrémenté dans l'inventaire.
5. **Mode B** : bouton `[⚡ PLACEMENT AUTO]` dans l'inventaire → lance `reduceToMinimumNew()` avec tous les fourreaux de la liste, affiche le panel de propositions.
6. **Mode C** : clic sur un type de fourreau dans la liste inventaire → active la grille visuelle existante (`toggleGrid()` ou activation forcée), désactive la gravité, affiche le compteur restant à placer. Chaque fourreau placé décrémente le compteur.
7. En Mode C, si la quantité totale N est définie, N "fantômes" semi-transparents prévisualisent les positions logiques (optionnel si trop complexe — signaler si non implémenté).
8. Les boutons `[−][+]` dans l'inventaire ajustent la quantité totale et recalculent le compteur `[placés/total]`.
9. Un feedback visuel (pulse ou highlight) confirme l'ajout à l'inventaire quand on clique `[+ Ajouter]`.
10. Tous les tests Jest existants passent (≥ 123 tests).
