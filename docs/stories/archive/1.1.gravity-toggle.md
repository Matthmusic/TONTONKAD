# Story 1.1 : Toggle gravité + mode placement précis par défaut

## Status

Ready for Review

---

## Story

**As a** électricien ou bureau d'études utilisant TontonKAD,
**I want** pouvoir placer des fourreaux sans gravité par défaut et activer la simulation physique à la demande,
**so that** mes fourreaux restent exactement là où je les pose, comme dans un logiciel de CAO, sans être perturbés par la physique.

---

## Acceptance Criteria

1. Au démarrage de l'application, `gravityEnabled = false` — aucun fourreau ne tombe.
2. Tout nouveau fourreau placé en mode `gravityEnabled = false` est automatiquement `frozen = true`.
3. Un bouton dans la toolbar et le raccourci clavier `G` permettent de basculer `gravityEnabled` ON/OFF.
4. Passage `gravityEnabled = false → true` : tous les objets `frozen` par le mode placement (flag `_frozenByMode`) sont unfreezés, les vx/vy restent à 0 (chute naturelle).
5. Passage `gravityEnabled = true → false` : tous les objets sont freezés (`frozen = true`, `vx = 0`, `vy = 0`), le flag `_frozenByMode = true` est posé.
6. Les objets freezés manuellement via `X` (flag `_frozenByUser`) ne sont PAS affectés par les transitions du mode gravité.
7. Un indicateur visuel clair dans l'interface affiche l'état courant : "GRAVITÉ ON" (icône active) ou "GRAVITÉ OFF" (icône inactive/grisée).
8. En mode `gravityEnabled = false`, le snap-grille et les virtual slots fonctionnent normalement (aucune régression).
9. Les performances restent < 16ms/frame (pas de recalcul inutile quand gravité OFF et tous objets frozen).

#### Distinction frozen manuel vs frozen par mode

Problème : `toggleFreezeAll()` et le mode gravité utilisent tous les deux `frozen = true`. Sans distinction, passer gravité ON unfreezerait des objets que l'utilisateur avait volontairement figés.

**Solution : deux flags booléens sur chaque objet**

```javascript
// À l'initialisation de chaque fourreau/câble :
_frozenByUser: false,   // posé par X / Ctrl+X
_frozenByMode: false,   // posé par mode gravité OFF
// frozen = _frozenByUser || _frozenByMode
```

**Règle** : `frozen` doit toujours refléter `_frozenByUser || _frozenByMode`. Ne jamais muter `frozen` directement sans mettre à jour l'un des deux flags.

#### `toggleGravity()` — logique complète

```javascript
function toggleGravity() {
  gravityEnabled = !gravityEnabled;

  const allObjs = [...fourreaux, ...cables]; // adapter aux noms réels dans script.js

  if (!gravityEnabled) {
    // Passage → OFF : tout figer sauf déjà frozen par user
    for (const o of allObjs) {
      if (!o._frozenByUser) {
        o.frozen = true;
        o._frozenByMode = true;
        o.vx = 0;
        o.vy = 0;
      }
    }
  } else {
    // Passage → ON : libérer seulement ce que le mode avait figé
    for (const o of allObjs) {
      if (o._frozenByMode) {
        o._frozenByMode = false;
        o.frozen = o._frozenByUser; // reste frozen si user l'a figé
        // vx/vy à 0 → chute naturelle depuis position actuelle
      }
    }
  }

  updateGravityUI();
}
```
