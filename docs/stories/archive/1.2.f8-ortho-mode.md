# Story 1.2 : Mode ORTHO F8 — contrainte de déplacement orthogonal

## Status

Ready for Review

---

## Story

**As a** électricien ou bureau d'études utilisant TontonKAD,
**I want** pouvoir contraindre le déplacement d'un fourreau à l'axe horizontal ou vertical en appuyant sur F8,
**so that** je puisse aligner précisément des fourreaux en rangées ou colonnes sans dérive diagonale, comme en mode ORTHO dans AutoCAD.

---

## Acceptance Criteria

1. La touche `F8` (sans modificateur) bascule le mode ORTHO ON/OFF globalement.
2. Un bouton dans la toolbar permet également de toggler le mode ORTHO.
3. En mode ORTHO ON, pendant un drag de fourreau ou câble, le déplacement est contraint : si `|dx| >= |dy|` → axe horizontal (Y bloqué à la position de départ) ; sinon → axe vertical (X bloqué à la position de départ).
4. La contrainte ORTHO est calculée depuis la **position de l'objet au début du drag** (pas depuis le curseur).
5. En mode ORTHO ON, les guide lines Konva s'affichent en **vert** (au lieu du bleu normal) pour signaler le mode actif.
6. Un indicateur visuel dans la toolbar montre l'état : bouton avec classe `btn-active` quand ORTHO ON.
7. Le mode ORTHO est **incompatible avec la gravité ON** : si `gravityEnabled = true`, F8 est ignoré et un toast "Mode ORTHO indisponible avec la gravité" s'affiche.
8. En mode ORTHO OFF, le comportement de drag est identique à l'état actuel (aucune régression).
9. Le mode ORTHO fonctionne indépendamment du snap-grille (`snapToGrid`) — les deux peuvent être actifs simultanément.
10. Après `onUp()` (fin du drag), la position de départ mémorisée est réinitialisée à `null`.

### Contrainte ORTHO — logique de calcul

```javascript
// dragStartPos = { x: obj.x, y: obj.y } capturé au startDrag()
// targetPos = position calculée (après snap éventuel)

if (orthoEnabled && dragStartPos) {
  const dx = Math.abs(targetPos.x - dragStartPos.x);
  const dy = Math.abs(targetPos.y - dragStartPos.y);
  if (dx >= dy) {
    targetPos = { x: targetPos.x, y: dragStartPos.y }; // axe horizontal
  } else {
    targetPos = { x: dragStartPos.x, y: targetPos.y }; // axe vertical
  }
}
```

**Important** : `dragStartPos` est en coordonnées **canvas pixels** (comme `obj.x`, `obj.y`). Ne pas confondre avec les coordonnées mm du monde.
