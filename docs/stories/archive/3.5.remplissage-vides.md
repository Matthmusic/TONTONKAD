# Story 3.5 : Remplissage intelligent des vides (N petits dans l'espace d'un grand)

## Status

Ready for Review

---

## Story

**As a** utilisateur de TontonKAD,
**I want** que le moteur détecte les espaces libres où N petits fourreaux pourraient remplacer un grand,
**so that** je puisse densifier l'occupation sans agrandir la boîte, avec une validation explicite avant application.

---

## Acceptance Criteria

1. Après un placement (auto ou grille), si un espace libre peut accueillir ≥ 2 petits fourreaux d'un type présent dans l'inventaire, une suggestion est affichée sous la forme d'une card ou d'un badge dans le panel.
2. La suggestion indique : combien de petits fourreaux seraient ajoutés, leur type, et dans quel espace (pas d'auto-application silencieuse).
3. L'utilisateur valide ou refuse via un bouton `[Appliquer]` / `[Ignorer]` sur la suggestion.
4. Si validée, les petits fourreaux sont ajoutés au canvas aux positions calculées, en respectant `entraxe` (30mm) et `litDePose` (40mm).
5. L'opération est **annulable via Ctrl+Z** (`saveStateToHistory()` est appelé avant l'application).
6. La détection est basée sur : l'espace restant dans la boîte (dimensions actuelles) moins les cellules occupées, comparé aux cellules nécessaires pour N petits fourreaux.
7. La logique de remplissage respecte les axes verrouillés : si la largeur est verrouillée, on ne propose que des remplissages qui tiennent dans la largeur actuelle.
8. Le remplissage est proposé uniquement si le ratio d'occupation final reste < 85% (éviter le surpeuplement).
9. Tous les tests Jest existants passent (≥ 123 tests).
10. Si aucun remplissage pertinent n'est détecté, aucune suggestion n'est affichée (pas de bruit inutile).

## Dev Notes

### Principe de détection (algorithme simplifié)

```
Pour chaque type "petit" (diamètre ≤ maxDiameter/2 ou depuis l'inventaire) :
  cellSize = diameter + ENTRAXE (30mm)
  surfaceOccupée = Σ (cellSizeFourreau)² pour tous les fourreaux placés
  surfaceBoîte = config.width * config.height
  surfaceLibre = surfaceBoîte - surfaceOccupée - (marges litDePose)
  
  nFit = floor(surfaceLibre / cellSize²)
  if nFit >= 2 AND (surfaceOccupée + nFit*cellSize²) / surfaceBoîte < 0.85 :
    suggestions.push({ type, diameter, count: nFit, positions: calcPositions() })
```

**Calcul des positions** : balayer la grille `config` en ligne/colonne, chercher les cellules libres (celles non occupées par un fourreau existant + hors marges).

### Constantes
```javascript
const LIT_DE_POSE  = 40; // mm — marge périmètre (litDePose dans placement-engine.js : PLACEMENT_RULES.litDePose)
const ENTRAXE      = 30; // mm — écart entre axes (PLACEMENT_RULES.entraxe)
```

### Vérifier dans placement-engine.js
```javascript

PLACEMENT_RULES.entraxe    // valeur attendue : 30
```

### Structure `NappeLayout` (placement-engine.js)
```javascript
class NappeLayout {
  constructor(width, height)
  placedFourreaux  // [{ id, diameter, x, y }] — x,y = coin bas-gauche cellule (Y=0 en BAS)
  width            // largeur totale incluant litDePose
  height           // hauteur totale incluant litDePose
  score
  scoreDetails
  alternatives
  calculateCellSize(diameter) // diameter + ENTRAXE
}
```

### Conversion coordonnées pour `addFourreauAt()`
Le moteur utilise Y=0 en BAS, le canvas Y=0 en HAUT :
```javascript
const cellSize = config.calculateCellSize(suggestion.diameter);
const x = (pf.x + cellSize / 2) * MM_TO_PX;
const y = (config.height - pf.y - cellSize / 2) * MM_TO_PX;
addFourreauAt(x, y, suggestion.type, true);
```
