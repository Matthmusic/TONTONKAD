# Stories & epics — archivé

Le suivi par **epics / stories** (méthode BMAD) n'est plus le fil directeur de
l'évolution du projet. Les documents de planification (epics 001 → 003, stories
1.x / 2.x / 3.x) sont conservés dans [`archive/`](archive/) **à titre de référence
historique** : ils ne reflètent pas nécessairement l'état actuel du code.

Pour comprendre le produit et sa direction, se référer plutôt à :

- [`PRODUCT.md`](../../PRODUCT.md) — définition produit
- [`DESIGN.md`](../../DESIGN.md) — système de design
- [`CLAUDE.md`](../../CLAUDE.md) — guide de contribution / architecture
- l'historique git (les commits `feat(...)` documentent les évolutions)
